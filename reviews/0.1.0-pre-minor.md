## Fix before the tag (verified majors)

- [ ] **[security, major, verified] decodeShareLink inflate cap fires after full inflation.** `src/share/index.ts:189`. `Inflate.push(bytes, true)` inflates everything before `ondata`. There is no input-length cap. `site/creator/app.ts:571` decodes `location.hash` on load. Reproduced: a 698,557-char link takes 2.2 s and +1.9-2.1 GB RSS before throwing. Fix: refuse a payload longer than `SHARE_LINK_BUDGET` before base64 decode, and optionally push the input in 4 KB slices so the cap stops the work early.
  **Clears when:** a new test in `src/share/share.test.ts` passes an over-budget payload and expects a length error, and a high-ratio bomb (for example 64 MB of zeros) is refused with bounded RSS or time. Both tests fail with the fix reverted.
- [ ] **[docs, major, verified] CLAUDE.md says "Nothing is built here yet" and "No code, `package.json`, build or tests yet".** `CLAUDE.md:7` and the status section. AGENTS.md and LANES.md route every agent here first. Fix: replace the status with the real state and the commands: `bun run check`, `bun run gate1`, `bun run build`, and the DRAMATIS_NETWORK/BROWSER/ENGINES tiers. Point to README Layout and LANES.md.
  **Clears when:** a Tier-0 or unit check fails if CLAUDE.md contains "Nothing is built"/"No code", or if it omits any `package.json` script. The check fails on the current file.
- [ ] **[docs, major, verified] The core's headline flow can't be run from the docs or the public API.** `packUrl` is undefined on `site/docs/export.md:15`, `dramatis-core.md:28` and `dramatis-three.md:100`. `readCharacter` and `decodeShareLink` need the full `settings` defaults. That set is `BUILD_SETTINGS` (src/build/settings.ts), and it is not exported from `dramatis`. The only other source is tosijs-3d/character, which imports Babylon. Passing partial settings silently drops sliders. Fix: export `BUILD_SETTINGS` (and the HM08 pack URL) from `src/index.ts`, and use them in the snippets.
  **Clears when:** a test runs (or mirrors) the export.md and dramatis-core.md ts fences against the public entry. A network-tier run is fine, plus a non-network test that `BUILD_SETTINGS` is exported and that `readCharacter(json, { settings: BUILD_SETTINGS })` keeps every key. Both fail with the fix reverted.
