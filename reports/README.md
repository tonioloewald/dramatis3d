# reports

Evidence from spikes and checks: what was run, on what, and what it showed (the
five-engine round trip, baked materials, VRM, the three.js embed, the slider
extremes sweep, load time on phones). One file per report, dated in its name,
e.g. `2026-11-02-spike-4-three-embed.md`. A check that did not run is reported
as not run.
