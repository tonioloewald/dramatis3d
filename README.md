# Dramatis

An open 3D character creator for the web. CC0 base data, GLB and VRM out, works in any engine, and nobody can buy it and switch it off. See [PLAN.md](PLAN.md).

Status: planning. The creator exists today as tosijs-3d's [character builder](https://3d.tosijs.net/character-builder/) and Dramatis is the product built on it.
